### 1. 报价与工程造价“代码隐形魔数”（高风险）

#### 1.1 价格库无面价时硬编码倒算系数 `0.4`
- **代码位置**：[`backend/extractor/pricing.py#L440`](file:///Users/qianqianawodebaobei/PycharmProjects/图纸扒图AI应用_drawing-extractor/backend/extractor/pricing.py#L440)
- **代码片段**：
  ```python
  cost_p = round(matched_lib["price_tax"], 2)
  list_p = round(matched_lib["list_price"], 2) if matched_lib["list_price"] > 0 else round(cost_p / 0.4, 2)
  ```
- **隐患分析**：当本地价格库只有含税进价而缺少公开目录面价时，程序直接写死 `cost_p / 0.4`（相当于预设 4 折进价）。然而电气行业不同品类的折扣差异巨大（如微断通常 5.5 折，塑壳 3.8 折，框架 4.5 折）。这会导致面价估算严重失真，进而影响 Excel 报表上展示的折扣率计算。
- **整改建议**：在 `pricing.json` 的 `brand_tiers` 或 `rates` 中提供 `default_list_price_discount`，缺失时根据该元器件品类读取对应标准折扣倒算。

#### 1.2 出厂综合利润率与税率作为函数默认值写死
- **代码位置**：[`backend/extractor/pricing.py#L831-L832`](file:///Users/qianqianawodebaobei/PycharmProjects/图纸扒图AI应用_drawing-extractor/backend/extractor/pricing.py#L831-L832)
- **代码片段**：
  ```python

      brand: str = "",
      profit_rate: float = 0.08,  # 8% 利润率

      use_ab_model: bool = False,
      ab_mode: str = "auto"
  ) -> dict:
  ```
- **隐患分析**：利润率 8% 和增值税率 13% 属于典型商务参数，不同项目、不同业主要求的税点和企业目标毛利率各不相同，目前未收录进 `pricing.json` 的 `rates` 段。
- **整改建议**：将 `profit_rate` 与 `tax_rate` 移至 `pricing.json` 的 `rates` 配置中，默认值从配置读取，支持通过环境变量覆写。

#### 1.3 型式试验与 3C 认证分摊费率写死 `2%`

  test_cert_cost = round(factory_cost * 0.02, 2)  # 固定 2%

### 2. 外部服务地址与运行环境强绑定（中风险）

#### 2.1 启动脚本主机与端口硬编码
- **代码位置**：[`run.sh#L13`](file:///Users/qianqianawodebaobei/PycharmProjects/图纸扒图AI应用_drawing-extractor/run.sh#L13)
- **代码片段**：

### 6. 合理保留、无需外置的规范常量（通过评审）

经核对，以下代码中的常数属于**物理公理、行业国际标准规范或协议常量**，保留在代码中是合理的工程实践，外置反而会导致出错面扩大：
1. **单位换算系数**：`/ 1000.0` (毫米转米)、`* 25.4` (英寸转毫米)、`/ 72.0` (点阵转英寸)；
2. **CAD 文件协议与 DXF 实体规范**：`"TEXT"`, `"MTEXT"`, `"INSERT"`, `"LWPOLYLINE"` 等 AutoCAD 几何类型；
3. **国际标准相序标记**：`1P`, `2P`, `3P`, `4P`, `L1/L2/L3/N/PE` 等国际电工委员会 (IEC) 规范标示；
4. **数学计算保护常数**：`1e-6`、`math.isfinite` 防除零或溢出保护。
